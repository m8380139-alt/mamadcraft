MamadCraft website starter

Files:
- index.html: page structure and content
- style.css: colors, layout, responsive styling
- script.js: server copy button, login/register (Nhost, username+password), profile, chat, gallery viewer
- images/: gallery photos

Run locally:
1. Extract the ZIP.
2. Open the MamadCraft-Site folder in VS Code.
3. Open index.html in a browser (or use Live Server).

Publish with GitHub Pages:
1. Create a new GitHub repository.
2. Upload index.html, style.css, and script.js to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait a little and open the published URL shown in Settings > Pages.
